2. CANVAS SYSTEM (backgroundCanvas, drawCanvas, etc.)
There are two separate applications with different canvas architectures:
A) main.html (основная комната) — Многослойная система
- Бэкграунд слой (layer index = 0 / back constant):
- Создается в createLayer() при инициализации.
- Константа back = 0 определяет его z-index.
- Инициализируется с изображением images/canvas1.jpg через setLayerBackground(back, 'images/canvas1.jpg').
- Размер: 600x400 (изначально).
- Имеет z-index = -100 (всегда ниже других слоев).
- Он не считается "слоем" в панели слоев.
- Выступает как фон, на который можно установить изображение или цвет через модальное окно backgroundSettingsModal.
- Рисовальные слои (layer index = 1, 2, 3, ...):
- Каждый слой — это отдельный <canvas> элемент, добавленный в canvasContainer.
- При создании (через createLayer()), канвасу задаются realWidth/realHeight (внутренние пиксели) и displayWidth/displayHeight (CSS).
- Все канвасы абсолютно позиционированы (position: absolute; top: 0; left: 0).
- Z-index определяется порядком в панели слоев (base Z = 110 + индекс).
- Каждый слой имеет свой context (contexts[layerId]), цвет (layerColors[layerId]), прозрачность (layerOpacities[layerId]), историю (history[layerId]), redo-историю (redoHistory[layerId]), и флаг layerDrawnOn[layerId].
- Слои обводки (outline layers):
- Для каждого слоя может быть создан отдельный слой обводки.
- Хранятся в объекте outlineLayers[layerNum] = { id, canvas }.
- Имеют z-index = (z-index основного слоя) + 1.
- Отрисовываются через createOutline() по пикселям (анализ альфа-канала соседей).
- Масштабирование (zoom):
- Все слои масштабируются через CSS transform: scale(zoomLevel).
- Zoom управляется зажатием Ctrl + движение мыши (горизонтальное).
- zoomOriginX/Y + offsetX/Y реализуют zoom в точку под курсором.
B) cancer/cancer.html (комната раков) — Трехслойная система
- Три канваса в одном контейнере:
1. backgroundCanvas (z-index: 1) — фон, CSS background-image: url('./images/canvas1.jpg').
2. overlayCanvas (z-index: 2, opacity: 0.5) — трафарет/оверлей.
3. drawingCanvas (z-index: 3) — основной слой для рисования.
- Все канвасы ресайзятся синхронно через resizeCanvases() под размер контейнера.
- High DPI поддержка: внутренний размер = clientWidth * devicePixelRatio, CSS = clientWidth.
- После ресайза контекст сбрасывается и затем масштабируется: ctx.scale(devicePixelRatio, devicePixelRatio).

4. HOW DRAWING WORKS
В main.html:
Основные переменные:
- isDrawing, isErasing, isSpider, isFinger, isDrawOnExisting — флаги режима.
- curCtx — контекст текущего слоя.
- lastX, lastY — предыдущая точка для рисования линии.
События:
- pointerdown → startDrawing(e): вычисляет координаты с учетом zoom, сохраняет точку, вызывает saveState().
- pointermove → draw(e): рисует линию от lastX/lastY к текущей позиции.
- pointerup → endDrawing(): сбрасывает lastX/lastY.
Координаты:
- Учет zoom: x = (clientX - rect.left) * (realWidth / displayWidth) / zoomLevel.
Режимы рисования:
1. Обычное (pencil):
- curCtx.beginPath(); curCtx.moveTo(lastX, lastY); curCtx.lineTo(x, y); curCtx.stroke();
2. Spider (паутинка):
- Рисует квадратичную кривую: curCtx.quadraticCurveTo(startX, startY, endX, endY).
- Соединяет точки с предыдущими, если расстояние < power.
- Точки хранятся в points[] и symmetricPoints[].
3. Finger (сужение к центру/смазывание):
- Использует ctx.clip() с кругом и ctx.drawImage() со смещением.
4. Draw On Existing (рисовать на существующем):
- Рисует только на непрозрачных пикселях (альфа > 0).
- Анализирует пиксели, смешивает цвета с учетом прозрачности.
5. Eraser (ластик):
- ctx.globalCompositeOperation = 'destination-out'.
6. Symmetry (симметрия):
- Рисует зеркальную копию относительно вертикальной оси centerX = realWidth / 2.
7. Flood Fill (заливка):
- Классический stack-based flood fill.
- Собирает референс со всех слоев, кроме текущего и фонового, для определения контуров.
- Поддерживает симметричную заливку.
8. Eyedropper (пипетка):
- Смешивает все слои на временный канвас, читает цвет пикселя под курсором.
Настройки кисти:
- brushSize (1-300) × pressure × масштаб.
- opacity (1-100) → curCtx.globalAlpha.
- outlineSize (0-20) → обводка (внешняя/внутренняя).
В cancer/cancer.html:
- Те же события pointerdown/move/up.
- Три режима: обычный, smooth (паутинка), симметрия.
- Координаты: e.clientX - rect.left (без zoom, с DPI scaling).
- drawSmoothLine: quadraticCurveTo + соединение с предыдущими точками.
- Overlay слой: копирует drawingCanvas, очищает его, устанавливает opacity.

function exportImage() {
    const exportCanvas = document.createElement('canvas');
    exportCanvas.width = realWidth;
    exportCanvas.height = realHeight;
    
    // Собирает все слои (main + outline) и сортирует по zIndex
    const allLayers = Object.keys(layers).reduce(...);
    allLayers.sort((a, b) => a.zIndex - b.zIndex);
    
    // Рисует каждый слой с учетом фильтров и прозрачности
    allLayers.forEach(layer => {
        tempCtx.drawImage(canvas, 0, 0);
        if (layerFilters[layerId]) {
            tempCtx.filter = layerFilters[layerId];
            tempCtx.drawImage(tempCanvas, 0, 0);
        }
        exportCtx.globalAlpha = layerOpacities[layerId] / 100;
        exportCtx.drawImage(tempCanvas, 0, 0);
    });
    
    // Создает ссылку для скачивания
    const link = document.createElement('a');
    link.download = 'my-drawing.png';

Типы файлового ввода-вывода:
1. Загрузка изображений на слой:

- Обработчик: UploadB → imageInput.click() → importImage(event).

2. Загрузка изображений для фона/канваса:
- backgroundImageInput (type="file", accept="image/*", multiple).
- canvasImageInput (type="file", accept="image/*").
- Обработчик: handleFileInput() → FileReader.readAsDataURL() → добавляет в galleryImages[] → вызывает loadFunction().
3. Экспорт (save):
- saveImageBtn → exportImage() → создает временный canvas → экспортирует через canvas.toDataURL('image/png') → создает ссылку для скачивания: link.download = 'my-drawing.png' → link.click().
